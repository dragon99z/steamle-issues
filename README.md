# Steamle – Issues

Public issue tracker for [Steamle](https://steamle.dragon99z.de), the daily game where you guess a Steam game from an anonymized review.

The source code lives in a private repository; this repo exists only so players can report problems and suggest ideas.

**[Open an issue](../../issues/new/choose)** – bug, wrong puzzle/review, or feature idea.

Please don't post personal data. Search existing issues first.
